# Prompt Karakter 3D Setengah Badan — Microsoft Designer / Bing Image Creator

> Versi setengah badan (pinggang ke atas). Setiap prompt sudah **lengkap**: tinggal copy satu blok, paste, generate. Panjang tiap prompt dijaga di bawah ±480 karakter (batas Bing Image Creator).

## Cara pakai

1. Buka **designer.microsoft.com** → *Image creator* (atau **bing.com/create**), login akun Microsoft.
2. Pilih ukuran **Square (1:1)** bila ada pilihan.
3. Copy satu blok prompt di bawah → paste → *Generate*. Biasanya keluar 4 gambar, pilih yang terbaik.
4. Buat **Tara dulu**. Untuk karakter lain, pilih hasil yang gayanya paling mirip Tara (cahaya, warna kulit, bentuk wajah, latar).
5. Download, ganti nama file **huruf kecil** (`tara.png`, `raka.png`, …), kirim ke chat.

`RISK`: kredit gratis harian terbatas; cek syarat pakai komersial Microsoft sebelum dipakai untuk klien berbayar.
