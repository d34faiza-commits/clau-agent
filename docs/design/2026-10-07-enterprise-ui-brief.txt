3. COLOR RULE
==================================================

Use color with discipline.

Approximate visual ratio:

70-80%:
White / very light slate / neutral surfaces

15-20%:
Deep navy / dark text / sidebar

5-10%:
Deep teal brand accents

Semantic colors should only be used for statuses and alerts.

Do NOT use orange as a major brand color.

Orange/amber can only be used for warning or pending states.

Do NOT make every button green/teal.

Primary CTA:
Deep Teal

Success:
Green

Warning:
Amber

Error:
Red

Information:
Blue
